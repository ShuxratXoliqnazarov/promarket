# pages — страницы

Каждая страница — папка со своими секциями:

```
pages/<page>/
├── ui/<Page>.jsx    # собирает секции в порядке макета
├── sections/        # секции, которые есть только на этой странице
└── index.js         # public API страницы
```

Секции импортируются внутри страницы относительными путями (`../sections/...`).
Снаружи страницы их не импортируем. Общие для нескольких страниц блоки — в `widgets/`.
