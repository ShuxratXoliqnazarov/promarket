# widgets — крупные блоки, общие для нескольких страниц

Метка в DOM: `data-section="..."`.
Виджет может импортировать features, entities, shared. Другие виджеты — нельзя.

Секции, которые есть только на одной странице, лежат внутри этой страницы: `pages/<page>/sections/`.
Если секция понадобилась на второй странице — переносим её сюда.

| Папка | Блок в Figma |
|---|---|
| `layout/header/` | Шапка сайта (на всех страницах) |
| `layout/footer/` | Подвал сайта (на всех страницах) |
| `product-slider/` | Заголовок + табы категорий + карусель товаров («Хиты продаж», «Акции») |
