# entities — бизнес-сущности

Запросы к API (`api/`) и отображение сущности (`ui/`). Метка: `@entity`.
Может импортировать только shared. Кнопки из features передаются в карточку через пропсы.

| Папка | Сущность |
|---|---|
| `product/` | Товар |
| `category/` | Категория |
| `collection/` | Коллекция плитки |
| `brand/` | Бренд |
| `article/` | Статья |
| `cart/` | Корзина |
| `favorite/` | Избранное |
