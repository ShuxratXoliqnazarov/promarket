# shared — переиспользуемое без бизнес-логики

Метка: `@shared` / `@shared-ui`. Ничего не импортирует из других слоёв.

| Папка | Что внутри |
|---|---|
| `api/` | экземпляр axios |
| `config/` | env-переменные (`VITE_API_URL`) |
| `lib/` | хелперы (`formatPrice`) |
| `assets/` | иконки и картинки |
| `ui/Container/` | обёртка с максимальной шириной контента |
| `ui/SectionTitle/` | заголовок секции («Хиты продаж», «Акции», «Статьи»…) |
| `ui/Button/` | базовая кнопка |
| `ui/Badge/` | бейдж «ХИТ» / «АКЦИЯ» |
| `ui/Rating/` | звёзды рейтинга в карточке товара |
| `ui/Carousel/` | карусель со стрелками (баннер, хиты, акции, статьи) |
| `ui/Logo/` | логотип (шапка, подвал) |
