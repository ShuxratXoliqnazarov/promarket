# features — действия пользователя

Кнопки и формы, которые что-то делают. Метка: `@feature`, в DOM: `data-feature="..."`.
Может импортировать entities и shared.

| Папка | Что делает | Где на макете |
|---|---|---|
| `search-products/` | Поиск товаров | Header |
| `select-city/` | Выбор города | Header |
| `request-callback/` | Заказать звонок | Header, Footer |
| `catalog-menu/` | Каталог товаров | Header |
| `filter-by-category/` | Табы категорий | home: Bestsellers, Promotions |
| `add-to-cart/` | В корзину | home: Bestsellers, Promotions |
| `toggle-favorite/` | Избранное | home: Bestsellers, Promotions |
| `quick-view/` | Быстрый просмотр | home: Bestsellers, Promotions |
